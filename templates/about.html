About The Project

Built for early, explainable diagnosis

Alzheimer's Disease Detection and Classification from MRI Brain Scans Using Convolutional Neural Networks (CNN) is an intelligent system designed to assist in the early detection and accurate classification of Alzheimer's disease through automated analysis of MRI brain scans.

Alzheimer's disease is a progressive neurological disorder that affects memory and cognitive function. Conventional diagnosis relies on manual interpretation of MRI scans by medical experts, which can be time-consuming and prone to human error. This system uses Convolutional Neural Networks to automatically extract features from MRI brain images and classify them into Non-Demented, Very Mild Demented, Mild Demented, and Moderate Demented categories, while Gradient-weighted Class Activation Mapping (Grad-CAM) provides visual explanations for every prediction.

Objective

Develop an automated, explainable, and web-deployable system that assists healthcare professionals in diagnosing Alzheimer's disease faster and more consistently than manual MRI review alone.

Approach

A custom CNN and a fine-tuned EfficientNetB0 transfer-learning model are trained on preprocessed, augmented MRI images, with the best-performing model deployed behind a Flask web application.
